## Расписания

Расписания на железной дороге нужны для двух разных целей:

- Публичное расписание помогает пассажирам добраться куда нужно: когда отправляется поезд? Можно ли пересесть с поезда на поезд?
- Служебное расписание вместе с поездными приказами используется для управления движением.

В Railroader расписания предназначены для опытных игроков, которым хочется больше сложности (и наград) в пассажирских перевозках.

- Расписание можно составить для собственных нужд — с поездными приказами или без.
- Если в расписании есть хотя бы один пассажирский поезд, пассажиры будут заранее собираться на станциях к поездам по расписанию. (Подробнее — ниже.)
- Автомашинисты пассажирских поездов, настроенные должным образом, будут ждать на станции времени отправления по расписанию.

### Основы расписаний

Расписания по умолчанию выключены. Включите их на вкладке «Настройки» окна компании, в разделе «Возможности». После этого в правом верхнем углу появится кнопка «Расписание», открывающая окно расписания. Его также можно открыть клавишей `F2` (по умолчанию).

В каждый момент действует только одно расписание. **Важно:** изменения при редактировании расписания не сохраняются и не применяются в игре, пока вы не нажмёте кнопку «Применить расписание».

Расписание — это список станций с востока (сверху) на запад (вниз). Поезда на запад показаны слева от станций (их читают «сверху вниз»), а поезда на восток — справа («снизу вверх»). Одни станции в расписании Railroader — пассажирские (Bryson, Wilmot), другие — просто разъезды (Thomas Valley). Использовать одни или оба вида — решать вам, но пассажирские возможности относятся только к пассажирским станциям.

### Создание расписания

Откройте окно расписания клавишей `F2` и нажмите «Изменить расписание». По умолчанию расписание пустое.

Если вы впервые работаете с расписаниями, рекомендуем стартовое расписание, входящее в Railroader. Щёлкните по значку шестерёнки и выберите «Загрузить готовое: Starter». Загрузится готовое расписание из двух поездов. Поезд 19 на запад отправляется из Sylva в 8:00 и через пару часов прибывает в Andrews. Там он разворачивается и становится поездом 18, отправляющимся из Andrews в 11:00.

Если ваша дорога ещё не доходит до Sylva или Andrews, будет показана только доступная часть.

Выберите один из поездов, щёлкнув по его номеру. На панели справа — подробности расписания выбранного поезда. Перечислены все станции, и у каждой есть флажок: есть ли у поезда время на этой станции. Для каждой отмеченной станции можно указать время прибытия и отправления, абсолютное («@») или относительное («+»). Относительное время — в минутах от предыдущего времени в расписании.

Для удобства рекомендуем задавать каждому поезду абсолютное время начала, а дальше — относительное. Так расписание намного проще править: изменения в начале не нужно вручную переносить вниз.

Важно: у поездов в расписании одно направление — на восток или на запад. Ветки тоже ориентированы по направлению относительно остальной дороги (Alarka — к западу от Alarka Jct по направлению дороги). Редактор расписания отключает станции, которые означали бы смену направления относительно уже выбранных станций. Для смены направления может понадобиться добавить в расписание ещё один поезд.

Скрещения задаются списком номеров поездов через запятую. Эта возможность только для отображения.

Номера поездов могут содержать только латинские буквы и цифры (0–9, A–Z). В Северной Америке это обычно число, например «21». Если хотите дать поезду более длинное название, используйте название бригады (см. ниже).

Не забудьте нажать «Применить расписание», если хотите пользоваться этим расписанием!

Чтобы сохранить расписание или поделиться им, используйте кнопки во всплывающем меню шестерёнки — они сохраняют расписание на диск и загружают его.

### Поведение пассажиров

Когда расписание действует, пассажиры начинают собираться на станциях, где по расписанию останавливаются пассажирские поезда:

- Пассажиры начинают собираться за час до прибытия поезда по расписанию.
- Пассажиры начинают расходиться после отправления поезда по расписанию.
- Пассажиры собираются к будущим остановкам из расписания, в том числе к тем, куда можно доехать с одной пересадкой.

Без расписания, или если в расписании нет пассажирских поездов, пассажиры собираются случайным образом.

### Настройка поездов и автомашинистов для работы по расписанию

Автомашинистов пассажирских поездов можно настроить так, чтобы они ждали времени отправления по расписанию. Для этого локомотив с автомашинистом нужно связать с поездом из расписания. Это делается через бригады: локомотив закрепляется за бригадой, а бригаде назначается номер поезда из расписания.

Понадобятся:

- Расписание с одним или несколькими пассажирскими поездами (см. выше).
- Бригада для этого поезда.

Затем:

- Откройте инспектор вагона (Ctrl-щелчок по локомотиву) и перейдите на вкладку «Перевозки».
- В списке «Бригада» выберите нужную бригаду.
- Когда бригада выбрана, появится список «Номер поезда». Выберите нужный поезд. (Это же можно сделать в окне компании на вкладке «Бригады» для этой бригады.)
- Чтобы автоматически отметить станции по расписанию, выберите пассажирский вагон, нажмите «Скопировать из расписания», а затем скопируйте на сцепленные. (Если кнопки нет, локомотив не связан с поездом из расписания — проверьте шаги выше.)
- Или включите «Автоназначение» на каждом вагоне. Тогда станции будут отмечаться автоматически по назначенному расписанию, включая возможные пересадки, но _только во время стоянки на станции_.

Автомашинист в поездном режиме или режиме путевой точки на локомотиве, связанном с поездом из расписания, останавливается на пассажирских остановках из своего расписания, _если время отправления ещё не прошло_, или если остановка отмечена в сцепленных вагонах. На остановках, которые отмечены в вагонах, но которых нет в расписании, он _не_ останавливается. Остановившись, автомашинист не отправится со станции раньше времени по расписанию.

Кроме того, выполнив последнюю остановку по расписанию, автомашинист установит максимальную скорость 0.

Когда поезд по расписанию закончит рейс и ему предстоит обратный путь, разверните поезд и выберите в редакторе бригады номер встречного поезда из расписания.

### Автомашинисты и грузовые/непассажирские станции

Сейчас автомашинисты соблюдают время по расписанию только на пассажирских остановках. Мы держим это в уме как возможное улучшение в будущем.
