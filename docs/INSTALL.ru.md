# Русификатор Railroader — инструкция

Неофициальный перевод [Railroader](https://store.steampowered.com/app/1683150/Railroader/) на русский язык.

**Что переведено:** интерфейс, сообщения и подсказки, названия грузов, этапы развития компании,
обучение (туториал) и справочник (`F1`).

**Что оставлено на английском:** названия станций, предприятий и железных дорог, таблички на путях
и список изменений игры (Release Notes). Так их проще сопоставлять с картой и с англоязычными
гайдами сообщества.

Русификатор работает через загрузчик модов **BepInEx 5** и не изменяет файлы игры.
Удаляется полностью, игра возвращается в исходное состояние.

---

## Требования

- Railroader из Steam (Windows). Проверено на **2026.1.0** (экспериментальная ветка). На обычной версии **2025.1.0b** эта сборка в игре не проверялась; справочник переведён по версии 2026.1, поэтому там он может немного расходиться с игрой.
- Steam Deck / Linux (Proton) — см. [раздел ниже](#steam-deck-и-linux-proton).

## Установка

### Способ 1. Автоматически (рекомендуется)

1. Скачайте архив `RailroaderRu-X.Y.Z.zip` со страницы **Releases**.
2. Распакуйте его в любую папку (например, на рабочий стол). Не запускайте файлы прямо из архива.
3. Закройте игру, если она запущена.
4. Запустите **`INSTALL.bat`**.
   - Установщик сам найдёт игру во всех библиотеках Steam.
   - Если не найдёт — попросит путь к папке игры (той, где лежит `Railroader.exe`).
5. Запустите игру через Steam как обычно.

> Если Windows показывает «Система Windows защитила ваш компьютер»: нажмите **Подробнее → Выполнить в любом случае**.
> Установщик — это обычный скрипт PowerShell (`install.ps1`), его можно открыть блокнотом и посмотреть.

### Способ 2. Вручную

1. Откройте папку игры: в Steam — правой кнопкой по Railroader → **Управление → Просмотреть локальные файлы**.
   Обычно это `C:\Program Files (x86)\Steam\steamapps\common\Railroader`.
2. Скопируйте туда из архива:
   - папку `BepInEx`
   - файлы `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`

   Файлы `INSTALL.bat`, `UNINSTALL.bat`, `*.ps1`, `README.txt` и `INSTALL.ru.md` копировать не нужно.
3. Запустите игру.

### Если у вас уже есть другие моды на BepInEx

Ничего особенного делать не нужно: установщик не трогает существующий BepInEx и добавляет только папку
`BepInEx\plugins\RailroaderRu`. При ручной установке скопируйте только эту папку.

---

## Проверка, что всё работает

- Главное меню и окна игры должны быть на русском.
- Если перевода нет, откройте файл `BepInEx\LogOutput.log` в папке игры и найдите строку
  `Railroader Russian ... загружен`. Если такой строки нет — BepInEx не запустился (см. «Частые проблемы»).

Первый запуск после установки может быть на несколько секунд дольше обычного — BepInEx создаёт свои файлы.

---

## Обновление русификатора

Скачайте новый архив и снова запустите `INSTALL.bat`. Старая версия заменится, настройки сохранятся.

## Обновление игры

После обновления Railroader русификатор продолжает работать. Если разработчики добавили или изменили
тексты, они будут на английском, пока не выйдет новая версия перевода.

---

## Удаление

Запустите **`UNINSTALL.bat`** из архива. Он удалит русификатор и, если других модов нет, предложит
удалить и сам BepInEx.

Вручную: удалите папку `BepInEx\plugins\RailroaderRu`. Чтобы убрать и BepInEx, удалите из папки игры
папку `BepInEx` и файлы `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `changelog.txt`.

## Настройки

После первого запуска игры появится файл `BepInEx\config\ru.railroader.localization.cfg`.
Его можно открыть блокнотом; значения — `true` (вкл.) или `false` (выкл.):

| Параметр | Что делает |
|---|---|
| `[Translation] UI` | перевод интерфейса |
| `[Translation] Tutorial` | перевод обучения |
| `[Translation] Guide` | перевод справочника (`F1`) |
| `[Fonts] CyrillicFallback` | подключение кириллицы к шрифтам, где её нет (заголовки, консоль) |
| `[Fonts] AutoSizeButtons` | уменьшение шрифта на кнопках, если русский текст длиннее английского |
| `[Translators] DumpUntranslated` | запись непереведённых строк в файл (см. «Помочь с переводом») |

Изменения вступают в силу после перезапуска игры.

## Частые проблемы

**Игра на английском, в папке игры нет `BepInEx\LogOutput.log`.**
BepInEx не запустился. Проверьте, что `winhttp.dll` лежит рядом с `Railroader.exe`, а не во вложенной папке.
Некоторые антивирусы удаляют `winhttp.dll` — добавьте папку игры в исключения и установите заново.

**Вместо русских букв квадраты или «мусор».**
Пришлите `BepInEx\LogOutput.log` (см. ниже). Временно можно попробовать `[Fonts] BundledFonts = true`
в файле настроек.

**Надпись не помещается в кнопку или окно.**
Сообщите, в каком окне, — лучше со скриншотом.

**Обучение «застряло»: цели выполнены, а кнопки «Далее» нет.**
Это ошибка самого обучения игры, русификатор её исправляет. Если вдруг повторится: на странице про
концевые краны помогает Shift-щелчок по соединительной головке рукава. Ещё можно закрыть окно обучения
и открыть заново кнопкой в правом верхнем углу — текущая страница начнётся сначала.

**«Проверить целостность файлов» в Steam удалит русификатор?**
Нет. Steam проверяет только файлы игры, а файлы BepInEx и русификатора — дополнительные.

## Steam Deck и Linux (Proton)

1. Установите русификатор вручную (способ 2) в папку игры.
2. В Steam: Railroader → **Свойства → Общие → Параметры запуска** впишите:

   ```
   WINEDLLOVERRIDES="winhttp=n,b" %command%
   ```

3. Запустите игру.

## Помочь с переводом

Словари — обычные текстовые файлы в `BepInEx\plugins\RailroaderRu\translations`, по одной строке
на фразу:

```
Original text=Перевод
```

- Файлы можно править прямо во время игры: после сохранения перевод перечитается сам
  (текст на экране обновится, когда окно перерисуется).
- Чтобы собрать все английские строки, которые встречаются в игре, поставьте в настройках
  `DumpUntranslated = true` и поиграйте. Они появятся в `BepInEx\plugins\RailroaderRu\untranslated.txt`
  уже в нужном формате — останется вписать перевод после `=`.

Присылайте исправления и найденные ошибки через Issues или Pull Request в репозитории проекта на GitHub.
Если сообщаете о проблеме, приложите `BepInEx\LogOutput.log` и, если можно, скриншот.
